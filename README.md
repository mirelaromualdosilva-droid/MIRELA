# 🌾 Projeto Agrinho: Inovação e Sustentabilidade no Campo

Bem-vindo ao repositório do projeto desenvolvido para o **Projeto Agrinho**. Este é um site interativo e responsivo projetado para conscientizar a comunidade escolar sobre a importância da agroecologia, da tecnologia sustentável e da preservação ambiental no agronegócio.

---

## 🎨 Identidade Visual
O projeto adota uma paleta de cores moderna e calorosa, destacando o **Laranja Vibrante** (`#FF6B00`) como cor de destaque (accent color), simbolizando a energia, o sol, a colheita e a inovação tecnológica no campo.

## 🚀 Funcionalidades
* **Design Responsivo:** Adaptável para celulares, tablets e computadores.
* **Interface "Clean" com Detalhes Laranja:** Layout focado na legibilidade e no impacto visual.
* **Quiz Interativo:** Um jogo de perguntas e respostas em JavaScript para testar os conhecimentos sobre o agro sustentável.
* **Seções Informativas:** Explicações dinâmicas sobre pilares da agricultura moderna.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica do site.
* **CSS3:** Estilização moderna utilizando variáveis, Flexbox e Grid.
* **JavaScript (ES6):** Lógica do Quiz e interatividade dos botões.
